Privacy Policy

Blackjack Quiz · app “blackjack-shorts” · last updated 1 November 2026

What this app is

“blackjack-shorts” is a private automation run by the owner of the Blackjack Quiz channels. It publishes the owner's own blackjack strategy videos to the owner's own YouTube channel and Instagram account. It is not offered to, and cannot be used by, anyone else.

Which data it accesses

  • YouTube (Google): with the owner's consent the app uses the YouTube Data API with the scopes youtube.upload (to upload and schedule the owner's videos) and youtube.readonly (only to show the connected channel's name during setup).
  • Instagram (Meta): with the owner's consent the app uses the Instagram API to publish Reels to the owner's own professional account.

How data is stored and shared

The access tokens are stored only as encrypted secrets in the owner's private GitHub repository and are used only to publish the owner's videos. The app does not collect, store, sell or share personal data of viewers or any other person, and it does not use Google user data for advertising. This website sets no cookies and uses no tracking. The “posted” checkbox on the start page is saved only in your own browser.

YouTube API Services

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service; see also the Google Privacy Policy. Access can be revoked at any time in the Google account permissions. Instagram access can be revoked in Instagram under Settings → Apps and websites.
